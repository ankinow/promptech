# Promptech

Prompt store global + ditado por voz local/offline para Linux X11 (i3), PT-BR.

## Features
1. **Prompt Store Global** — Espanso: search bar em qualquer janela (`$mod+Space`), Forms com slots dinâmicos para prompts longos de IA.
2. **Voice-to-Text** — whisper.cpp large-v3-turbo (WER ~4% PT-BR) local; toggle numa tecla única; texto injeta na janela focada via clipboard+paste (preserva acentos e o clipboard do usuário).
3. **Overlay Picker Unificado** — popup único (rofi-style): buscar prompt OU iniciar ditado.

100% local · zero nuvem · Arch/CachyOS-first.
